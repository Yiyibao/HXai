# 仍需继续开发的功能

只列当前树还没关闭的产品缺口。已修的预检、epoch、撤权、无记账拒绝和 OCR 缓存位置不再列入。

## 先做环境门禁

这些不是新功能，但不做就不能把现有功能称为可用。

1. 用项目外 Flutter 重新生成 Pigeon，并核对本次手工改动的 `study_host_api.g.dart` 与 `StudyHostApi.g.kt` 没有漂移。
2. `flutter analyze`、`flutter test`，以及 `client` 的 Debug 单测和 lint。无 SDK/`local.properties` 时不要复制工具链进仓库。
3. 冻结 QA 包后，在已归属的 API26/API34 上复验：双会话/双档案抢槽、停止与批准的旧 epoch、文档撤权、模型锁。
4. Release AAR 与 unsigned/正式签名宿主分开取证。Mate 50 / HarmonyOS 4.2 冷启、锁屏、force-stop、网络恢复仍是独立层。
5. 新的文档撤权路由必须先于依赖它的客户端发布。旧服务没有该路由时，客户端应保持失败并保留本地凭据。本轮没有部署生产。

## P0 仍开放

- 目标验收仍有模型判断。工具谓词和 `UNSUPPORTED`/`DISPROVED` 已不能单独变成成功，但自然语言目标的最终接受仍会询问模型。若要求完全不依赖模型判断，需要新的确定性验收器，而不是再包一层文案。
- 主 Chat 的 MCP 工具仍未接入。原因是缺逐服务器、逐工具的运行时授权；schema 不能当授权。要做就必须先有安装、范围和逐任务审批，不能为了入口把 `mcpManager` 直接塞进 `ChatToolFactory`。
- 云托管密钥仍是 `ABSENT`。没有实现就不能写成可托管。
- 跨 App 与截图远传保持关闭。若要打开，必须有前台确认、可见停止和任务级授权，不能靠默认开关。

## P1 仍开放

- LibreOffice / MinerU 容器、无网络、只读输入、杀进程和产物回读。本机 ASGI 164 项通过不是容器通过，也不是 Office 像素保真。
- WPS 与 Microsoft Office 的实际打开、隐藏页和公式缓存仍要各自验证。
- 教材印刷页还没有绑定到文件版本，不能用 PDF 物理页代替。
- 服务端撤权不会证明已经 dispatch 的容器已停止。调度器取消路径仍要在真实容器上复验。

## P2 仍开放

- 现有核验器只覆盖已声明的代数、有理函数和有限区间证书。一般证明、极限积分交换和自然语言原题全覆盖仍不是已交付能力。
- 没有人工题库，不能报数学准确率。
- 真实 OCR、手写和公式识别质量未验收。缓存位置已改，识别质量没有因此提高。

## 明确暂缓

百度网盘、邮箱、日历连接器仍按现有决定暂缓。不要为了功能清单启用没有安全契约的工具。
