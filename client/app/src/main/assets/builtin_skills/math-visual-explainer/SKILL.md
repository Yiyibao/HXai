# 数学题的图像辅助讲解

用户无需说出技能名称或主动要求绘图。适用时读取本技能，再结合图片或文字回答。

1. 从当前图片识别题干、方程、定义域、参数条件和原图关系。先简短列出影响解题的关键条件。只有模糊符号会影响结论时才请用户确认；不凭图片外观推断垂直、相等、比例或坐标。原图无法读取时说明限制，不假装完成识题。
2. 函数性质、交点、切线、圆锥曲线等适合配图时调用 `render_math_plot`。模型给方程，绘图工具计算坐标；禁止凭空编造采样点或调用图片生成模型代替精确数学绘图。
3. 方程转为工具的受限公式：显式乘号 *，幂 ^，括号；函数 sin/cos/tan/sqrt/abs/ln/log/exp，常量 pi/e，三角函数使用弧度。ln 是自然对数，log 是常用对数。不支持的式子不能擅自改变数学含义。
4. 结合图形解释推导，明确图像与数值结果是辅助证据，精确答案由代数或几何推导给出。关键点标注来自已推导的坐标，不把工具绘图称为自动证明、精确求根或符号求解。
5. 固定题目条件保持固定。只有用户要求探索，或可变参数有助理解时添加滑块；限制滑块范围，避免分母为零或不满足题设。用户改变参数后，把探索情形与原题答案区分开。
6. 参数可能使关键点移动时，不添加静态关键点误导用户；将推导出的焦点、顶点等作为固定条件标注，或在文字说明其参数关系。无关曲线、辅助线与控件不要堆叠。
7. 圆与圆锥曲线默认等比例坐标轴。合理选择视窗和参数范围，不把视窗外部分当成不存在；分段函数分成多条有定义域限制的曲线；双曲线分成两条参数曲线。失败后修正结构或使用文字推导，并说明未成功绘图。

## 生成形式

`render_math_plot` 的 definition 是 JSON 字符串，使用版本 3 的交互界面：包含 text 说明、可选 slider、一个 math_plot、可选继续分析 button。math_plot 通常单独占一行。必须注明公式来自题目、推导或探索假设。工具同时交付当前默认参数下的真实 PNG 文件；交互变化不会改写已交付 PNG。

math_plot 字段：id/type、xMin/xMax/yMin/yMax、equalAspect（默认 true）、curves、可选 points。
曲线最多 6 条，label 是图例，kind 为 function/parametric/implicit。
- function：expression，例如 `a*x^2+b*x+c`；可选 min/max 限制 x 定义域。
- parametric：x/y 公式，例如椭圆 `3*cos(t)` / `2*sin(t)`，必须给 min/max，例如 0 到 2*pi 的数值 6.283185307179586。
- implicit：expression 表示 F(x,y)=0，例如 `x^2/9+y^2/4-1`。这是数值等值线，小于采样网格的结构可能遗漏；标准圆锥曲线优先参数形式。
- points：[{x:数值,y:数值,label:名称}]，只标已核对的固定坐标。

例：椭圆与可变直线。椭圆 parametric x=`3*cos(t)`、y=`2*sin(t)`、min=0、max=6.283185307179586；直线 function expression=`k*x+1`；slider id=k、min=-3、max=3、value=1；视窗 x/y 都为 -5 到 5。先推导交点/相切条件，滑块只用于探索，不使用图像代替判别式证明。
