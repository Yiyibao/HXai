# 增强搜索与思考过程显示

按顺序完成搜索能力接线，再修改思考区域。保持现有真实模型配置与会话。

## 搜索

- 新助手默认允许联网，工具工厂也对旧助手开放 `search_web`；模型内置搜索与增强搜索可同时使用。工具默认无需审批。系统提示明确允许模型按需调用。
- 通用搜索入口统一调用增强搜索。保留文字、引用、发布时间、摘要和查询；图片地址去重、限制数量，并保留提供方明确返回的来源。没有依据的作者、日期和来源不再猜测。
- 默认 Bing 增加独立的图片候选检索，图片检索失败不丢弃网页结果。Exa、Doubao 保留明确的图片来源信息。
- 当前为图片候选返回，不保证每张图片相关或可加载，也不强制每次搜索都配图。其他服务的图片能力仍取决于其适配器。
- 实网查询 `aurora nasa`：Bing 图片页 HTTP 200，包含 25 个候选节点。抽样 3 个图片地址 HEAD 返回 HTTP 200 / image/jpeg；另一个地址返回 403。记录见 `bing-candidates.json`、`bing-image-probe.json`。该检查不是对图片内容和来源真实性的人工验证。

## 思考区域

- 用紧凑状态行代替紫色脑图标和 ExpansionTile；默认收起，点击展开。同一条回答的多个思考段合并成一个入口，详情保持返回顺序。
- 状态接通消息 RUNNING、完成、中断以及后续正文/工具片段，避免开始回答后仍显示思考中。
- 展开内容保留模型实际返回的 Markdown；淡色竖线、次级文字、长内容滚动。流式更新保留展开状态，不编造耗时或思考内容。
