# R5 Skills 与收尾自审

Flutter 设置已接入真实 Skills 列表、原生导入入口、逐助手启用、依赖与许可证说明、备份恢复和文档服务入口。档案与界面版本校验拒绝陈旧操作；列表刷新丢弃切档案前的旧响应。纯说明、引用资料、内置文件工具型技能分别验证。技能 Office/PDF/图片/CSV 资产先导入当前档案的真实材料库，再由内置工具处理，不将二进制当文字。

兼容说明依据 [Agent Skills 规范](https://agentskills.io/specification)。`license`、`compatibility`、`allowed-tools` 可查看；后者不授予权限。当前客户端可加载说明与资源，不能执行社区 Python、Node、Shell、LibreOffice 等完整脚本流程。依赖型技能标为部分兼容。导入与启用不代表所有依赖已安装，也不能解除用户的上传限制。

社区样例固定为 anthropics/skills 提交 `683bc88e56f3e09ba94f7055977f3d3aa499f202`：internal-comms 的说明和引用资料逐字节加载；docx 的缺失运行环境及 Proprietary 声明可见。文件来源、摘要与用途见 community-sources.json；仅作本地兼容测试，没有打包为内置技能或宣称其完整流程执行成功。

自审修复：技能资产归属及摘要复用；过期启用与刷新响应；交互 metadata 随加密备份恢复；非法交互定义和本地编辑失败改为确定的错误结果，使模型能够纠正；远端提交丢失确认时保留持久化意图，同标识恢复，服务配置变更拒绝重新上传。新增断线恢复测试没有发起真实网络请求。

截图复核修正了文件卡片的长 MIME 展示和默认展开的工具参数：文件类型改为可读名称，处理详情折叠，需要批准的请求展开。档案切换失败显示错误。模拟器交付测试曾因 Flutter 合并无障碍标签而未定位文件卡片，改为匹配合并标签中的完整文件名；截图等待首帧，仍通过真实按钮及独立应用验证交付，没有改为调用桥接来绕过按钮。

最终验证结果及对应 APK 见 [完成记录](completion.md)。保留原件的 Office 编辑、PDF 页序、四个实际产物摘要和未改动包部件已复核；证据在 editor-artifacts/。合成会话、临时助手、技能安装样例与测试另存文件由各测试清理；R1 旧排版合成会话另行精确清理。实现用临时脚本已移除，保留可复用的资源核对、文件审计和公开样例准备脚本。

范围：首批 Word 简单段落、Excel 常量单元格、PDF 选页合并拆分和文字版 PDF 转换。PPT 生成沿用既有能力，没有新增 PPT 保真编辑。复杂格式、完整社区脚本、所有模型在线兼容、真实 MinerU 与模型自动续聊联合流程、Mate 50、跨真实设备迁移及签名发布不在已通过的验收结论中。
