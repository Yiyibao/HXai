# R3 文件聊天闭环自审

复用现有 MaterialFiles、MaterialReader/Writer、已部署的版本1文档服务合同和15分钟后台同步，不重建服务。当前聊天被观察时按10秒间隔查询实际任务；后台由已有 Worker 下载，重开原会话后续聊。原生将完成的工具输出 Document/Image 传给 Flutter；成果卡片提供打开、系统另存、分享。另存写入后重读校验摘要，文件打开/分享前校验原文件，MIME与ClipData正确授权。

文件工具调度改为任务驱动，优先本地读取/模型视觉；仅上传无任务禁用远端提交；用户消息的“仅本地/不上传”限制持续生效，明确允许后可解除。文件正文不能改变权限。扫描图片传递材料ID；本地提取失败保留元信息和未读取范围，允许后续选择工具。关闭服务或仅本地仍可读已校验缓存。

解析任务的来源与当前分支消息、工具、材料及页范围绑定。只有真实下载校验后的缓存能触发确定ID的续聊；重复观察、回调和重试不重复入队。坏缓存显示校验错误，失败任务重试创建新的聊天请求，取消不假装成功。远端错误保留原件与任务，展示原因。没有捏造百分比或全文完成。

自审修复：附件结果漏传；图片无材料ID；旧OCR显式请求限制；禁远端误禁缓存；校验失败的刷新误报成功；已取消任务误续聊；失败重试未接入；Flutter交付错误忽略；成果按钮窄屏溢出。验证方式修复：两Gradle并行争用KSP后改为单调用。

证据：r3-final-build.log JVM与debug/test APK构建通过；r3-analyze.log无问题；r3-flutter-test.log 45项通过，r3-delivery-widget-test.log 4项通过（含成果按钮真实桥接与失败提示）；r3-bridge-runtime.log 4项模拟器通过，包括真实docx生成/文件卡片/另存摘要、篡改和跨档案拒绝、校验缓存续聊、重复回调去重、坏缓存不续聊、失败重试去重。32个Flutter资源匹配APK（r3-build-manifest.json）。

边界：本批新执行的解析/模型续聊测试用明确合成缓存与本地假模型服务器，未冒充在线MinerU/真实模型联合验收；既有HTTPS部署证据仍见qa/document-service。交付工具沿用既有FileProvider，真实跨UID接收和Mate50最终交付在R5补充。服务Office编辑未部署，本批不承诺它；R4首批本地编辑复用已有文件产物库。
