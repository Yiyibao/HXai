# R2 智能 UI 自审

采用自有有限 JSON 组件目录 v1，复用已有工具调用和会话树。GenUI 0.10.7 / A2UI 0.9.1 仅候选，不宣称完整协议兼容。Flutter 官方仍注明 alpha：https://docs.flutter.dev/ai/genui；目录版本参考 https://github.com/flutter/genui 和 https://a2ui.org/。避免引入第二套模型客户端，后续可在组件目录边界接适配器。

已实现文字、卡片、表格、折线/柱状/散点、滑块、下拉、输入、线性计算和续聊按钮。仅成功执行的原生 render_interactive_ui 工具结果可以呈现交互；普通正文无法执行界面动作。定义大小、类型、参数、引用和状态均双侧校验；陌生类型保留工具文本。工具定义/输出已随 Room 消息保存；本地状态暂存在按档案/会话/消息/工具/定义摘要隔离的持久存储，R4 扩展正式状态备份。

自审修复：拒绝数值字符串；下拉恢复真正显示保存选项；非法或变更动作在写状态前拒绝；图表裁剪；加载失败可重试；动作失败重试保持请求 ID；队列内再次核对当前分支。

验证：app JVM 全套通过（含新增3原生校验），SDK全套通过（新增 Responses/ChatCompletions 各1目录保留测试），Flutter analyze 无问题、5组件测试通过；模拟器 FlutterChatBridgeTest 两项通过，覆盖普通聊天、状态恢复、越界/过期/切分支拒绝、动作续聊、重复请求去重。预算、文件表格、函数图表均为明确合成数据，未声称实际模型生成或两家供应商在线验收。32个Flutter资源与APK一致，见 r2-build-manifest.json。
