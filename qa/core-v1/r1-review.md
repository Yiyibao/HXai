# R1 通用聊天与桥接：自审记录

## 实现

通用 CHAT 模式作为新会话默认；旧四种教学模式和用户自定义提示词保留。仅识别完全相等的旧出厂提示词，在通用聊天中使用新默认；不覆盖用户设置。Kotlin 核心仅在用户选择教学模式时加入教学闭环。

Flutter 消费原生会话和生成状态事件，从真实活动 session 获取快照；增加历史侧栏、分页、局部搜索、重命名和删除。附件经 Android SAF 导入、所属校验及 SHA-256 校验后进入会话；显示本地图片与文件卡片。Markdown 标题、表格、代码及 LaTeX 完整渲染。模型配置复用原生页面，模型选择校验提供商所属。

发送确认等待队列持久化；同一请求使用稳定消息 ID，恢复后的队列和历史防重复提交。请求摘要落盘，拒绝用同一标识修改内容。发送失败保留草稿。审批和分支选择复用 ChatService 的审批续行和分支保全路径。

## 自审发现与修复

1. 初版请求去重仅在内存：改为持久化请求摘要、确定性消息/新会话 ID 和队列提交去重。
2. 初始化读取默认档案早于设置恢复：等待 settings.init=false，并在 Flutter 先完成 bootstrap；模拟器冷启动暴露后修复。
3. Riverpod 自动重试身份错误导致一直加载：bootstrap 与会话请求关闭自动重试；显示错误与明确重试入口。
4. 模型刷新重置当前会话：改为首次初始化会话 ID，随后保留显式选择。
5. 无订阅生命周期和档案边界：绑定档案/epoch，观察期间持有会话引用，取消和销毁时释放；各档案数据桥接校验当前所属。
6. Java file URI 无法纳入附件引用跟踪：统一使用 Android file:// URI。
7. Markdown 冒烟测试只能证明挂载：增加标题、表格、代码和公式内容断言，包括代码中的数学标记与半截流式表达式。
8. 可视检查中复制按钮覆盖长公式：为滚动公式视口预留独立按钮区域。
9. 旧合成排版夹具绕过显式新建合同：测试夹具明确声明 newConversation=true；修正测试而不放宽生产写入规则。
10. 旧 saveArtifact 虚报成功：暂改为明确不可用；真实另存属于后续 R3，不能以空实现返回成功。
