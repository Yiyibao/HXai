# 聊天文件服务自动调度

2026-10-11。用户只需上传文件并说明任务，模型根据任务和本轮实际可用能力选择工具，无需用户指定解析器。

## 实现

- 聊天系统提示按实际工具可用性生成自动调度规则。可读文本和普通 Office 优先本地读取；扫描内容、公式或表格结构提取不足时主动使用已启用服务。只有附件没有任务时不自动上传。
- PDF 附件及本地分页读取工具提供真实总页数、尝试提取页数和无可提取文本页码。无文本页也可能空白，不据此声称一定有扫描内容。升级读取缓存版本以重新提取历史 PDF 的这些信息。
- 新增 list_material_parse_results，查询当前档案同材料版本的已校验结果或当前配置的有效任务，分页最多20项，不上传文件。排除损坏缓存、源摘要不匹配和已取消任务，模型可先复用已有处理范围。明确重新提交时，单任务及批任务不再复用损坏的已下载缓存，避免反复返回不可读取的旧任务。
- 全文超过5页仍使用完整请求范围，由已有客户端批处理和自动续聊执行。模型收到下载完成通知后分页读取结果再继续回答，不重复提交或密集轮询。
- 用户禁止上传、服务停用及模型未开启工具调用能力时，提示与实际工具定义保持一致。模型没有工具能力时不宣称远端解析可用。
