# 全项目复审覆盖矩阵

|领域|本轮代码核查|本轮验证及边界|
|---|---|---|
|构建/身份/配置|Gradle、Manifest、独立应用标识、Debug/签名、入口|当前 Debug APK/测试包构建成功；Release 签名/发布未执行|

|其他模型协议/搜索/语音|测试与 SDK 边界；不把协议单测当所有服务实测|search/speech/oauth 等 JVM；全部远端提供商/UI未逐项E2E|
|档案/数据访问|仓储 owner、DAO/FTS 查询、搜索/历史、页面切换、入口禁用|模拟器档案/越权/页面专项；不是强设备多用户隔离|
