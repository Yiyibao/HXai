# 项目分组与手动记忆验证记录

日期：2026-10-11。需求来自本轮用户：项目用于特殊需求聊天分组，记忆支持手动添加。

## 交付

- [ARM64 Debug 安装包](MathStudyAgent-project-memory-arm64-debug.apk)
- [使用与实现说明](../../docs/project-memory-20261011.md)

项目支持创建、重命名、项目内新聊天、移动/移出聊天、删除分组保留聊天。项目及聊天按档案和助手隔离，项目列表查询只读取必要元信息。聊天移动及分组删除通过 ChatService 同步内存会话，后续保存不会写回旧归属。

手动记忆支持偏好和背景，提供保存进度、错误保留草稿及档案切换保护。记忆使用 USER_MANUAL 来源、自述证据及已有本地存储，支持检索、版本编辑、删除抑制和备份恢复。它不依赖聊天来源，不作为正式掌握度证据。

## 发现与修复

首轮页面编译发现 WidgetRef 不提供 mounted 属性，已改为页面生命周期检查；旧侧栏测试依赖“即将推出”占位，已改为项目空状态并提供明确的测试数据。

首轮模拟器新建项目聊天卡住：外层 Room 写事务持有写锁，而现有会话仓库的 FTS 索引切换 IO 线程等待写锁。首轮已中止，失败日志保留于 [首轮日志](android-first-run.log)。已让会话仓库独立完成自身事务及提交后索引，并为专项测试添加超时。最终重新构建与专项复验通过。

自查补齐活跃会话内存归属同步，并扩展专项测试验证后续保存不会撤销移动、不会恢复已删除的分组。
