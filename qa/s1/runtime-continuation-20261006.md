# S1 设备网络、持久化队列与工具接续

2026-10-06，AOSP Android 34 x86_64 模拟器。此批使用合成 HTTP/SSE、本地无副作用工具与真实 Android 默认网络变化；没有调用真实中转或读取个人会话正文。

## 实现

- Room 27→28 自动迁移新增 `ConversationEntity.queue_state`，默认 `{}`。排队内容、稳定输入 ID、是否需要回答和暂停状态持久化；编辑占位和语音 Deferred 仍为内存状态。恢复后有内容的队列先暂停。
- 入队、编辑、移除和暂停先提交再展示；队列操作按调用顺序串行。排队输入出队与成为用户消息共享 Room 事务及消息 ID，失败保留输入，不产生半次提交。普通元数据保存保留数据库中的队列，附件引用检查包含排队输入。
- 生成期间监听设备默认网络；断开或换路由取消本轮，归类 INTERRUPTED，保留已提交内容并暂停队列。恢复网络不自动重放；用户可重新生成或恢复队列。
- 工具新增 NOT_STARTED/RUNNING/INTERRUPTED/COMPLETED 执行状态。每个工具执行前先保存 RUNNING，结果保存完成后才允许下一工具开始；空成功结果也算完成。已完成工具结果用于接续。
- 取消、进程恢复及工具执行开始后的异常，将没有结果的 RUNNING 工具保留为 INTERRUPTED，即执行结果未知；可能已产生效果，不能自动或直接重放。界面提供“跳过未知工具并接续”，先保存明确 unknown 结果再继续原轮，不重复用户消息。
- 审批等待使用 WAITING_TOOL；恢复的 Auto 调用重新检查当前工具的审批要求。旧分支、已完成工具和迟到审批不被本次审批改写。

## 验证

| 验证 | 结果 |
|---|---|
| 飞行模式开启→默认网络消失→关闭恢复 | 部分回复保留为 INTERRUPTED，排队内容落盘且暂停；恢复网络无新请求；人工恢复队列只新增一次用户输入 |
| AndroidWifi Wi-Fi→CELLULAR 默认网络 | 切换前后的实际 ConnectivityManager transport 被断言；部分回复保留；无自动重放；人工重新生成不重复用户输入 |
| 队列 Room 重开和原子提交 | FIFO 内容与 ID 保留，重开先暂停；普通元数据保存不覆盖队列；重复提交被拒绝 |
| 工具空成功结果后下一工具中断 | 工具函数内读取 Room，确认开始标志和前一个结果已提交；空结果不重执行；恢复后下一工具结果未知；手动跳过后原轮继续 |
| 工具函数抛 IOException | 结果未知，后续工具不执行，不发模型请求，不伪造失败输出 |
| 恢复 Auto 调用仍要求审批 | 审批状态和 WAITING_TOOL 落盘；零工具执行、零模型请求 |
| Room 27→28 | 独立测试库重建为 27 后实际迁移，所属档案、标题、置顶与消息节点保留，新队列默认空 |
| checkpoint seed→force-stop→新 Android 进程 verify | 不同 PID；消息、排队输入 ID 和文本保留；队列暂停；已完成工具保留，运行中工具恢复为未知；未启动任务 |

最终 Android 故障套件 **16 项**，跨进程恢复 **2 个阶段**；app JVM **244 项**、ai JVM **197 项**，均 0 failure/error。机器可读结果及 APK SHA256 见 [结构化证据](runtime-continuation-20261006.json)，HTTP 子项见 [故障证据](network-faults-20261006.json)。

复跑入口：`scripts/test_s1_runtime_continuation.ps1`（构建、覆盖安装、16 项故障测试、跨进程两阶段验证）；`-SkipBuild` 只在当前 APK 与测试 APK 已构建时使用。限定 emulator 序列号。Wi-Fi 连接命令需要本 AOSP 模拟器的 `su 0`，不适用于普通真机。测试恢复原模型/助手/代理设置、飞行模式和 Wi-Fi 开关；删除本轮合成会话及独立迁移库，不清应用数据。构建临时 Firebase 占位文件已移除。

开发轮次曾提前安装尚未完成打包的旧 APK，导致 NoSuchMethodError；后续等待完整构建结束后重装解决。Wi-Fi 初轮普通 shell 被系统拒绝，改用模拟器 su 后验证成功。跨进程脚本最初在仪器结束后读取 PID，此时测试进程已经退出；改为仪器状态回传 PID。恢复测试初轮把含工具消息的 `toText()` 当作纯文本比较，现同时比较原始恢复前文本及 Text part。失败轮次不计入最终 PASS。

## 边界

这是模拟器子项的证据，不整体宣布 S1、C04/C05 或 R01 完整通过。HTTP/SSE 使用 Android loopback 服务，真实设备网络变化由默认网络回调触发中断，尚未验证真实远端服务同时经 Wi-Fi 与移动网络访问；生产 10 分钟读超时未完整等待；跨进程样本在已提交检查点后终止，没有强杀正在产生真实外部效果的工具。Mate 50、完整后台限制与真实外部工具效果核查仍待验收。新增工具恢复按钮完成编译与业务接续测试，本批未新增其可见界面截图；前批恢复截图仍属于前批 APK。
