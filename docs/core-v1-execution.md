## R0 基线核查（已完成并自审）

- 复用 Kotlin 的 ChatService、会话树、模型 SDK、材料仓库、文档任务、Skills、凭据和备份；Flutter 负责主界面。
- 修改强制教学、Flutter 功能接线、交互消息和文件任务。保留旧会话教学枚举、学习记忆及数据隔离。
- MCP、电脑控制、浏览器自动化、多 Agent 平台暂缓。
- 工作区存在大量既有未提交改动，不重置、不以 HEAD 代表当前基线。旧 APK 和原生测试不能替代新 Flutter 主入口验收。
- 自审修正：需求中的“当前先梳理需求，不改代码”是前一轮历史范围；本轮以用户的新实施授权为准。GenUI/A2UI 仍须原型评估，不直接宣称选型完成。
