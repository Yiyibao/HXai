# 数学可视化作为智能 Chat 的内置能力

## 实施顺序与分工

1. 内置 `math-visual-explainer` Skill：发现适合配图的文字/图片题，核对关键条件，组织解答和图像。应用随 APK 安装技能，加入模型可发现的 Skills 清单；不需要用户先手动启用。用户当次不画图、只提示等要求优先。
2. `render_math_plot`：受限公式解析、本地数值采样、Android Canvas 真实 PNG 输出，写入当前档案的成果库。复用文件哈希校验、预览、保存、分享。相同定义的成功快照可复用，失败不生成成功界面。
3. 图文讲解：Skill 要求说明题目/推导/探索的公式来源，把解答步骤对应到图中。图片使用已有视觉模型输入；识别不清且影响结论的符号要求核对。
4. `math_plot` 组件：嵌入消息的坐标图，滑块重新计算曲线、双指缩放、图例和关键点、继续追问，复用现有 revision/档案/分支校验与会话状态持久化。

本轮选择本地确定性计算，而没有新部署 SymPy/Matplotlib 服务：常见高中函数和圆锥曲线无需服务端即可绘制，并支持离线重开后的交互。现有文档解析服务器不承担数学绘图。未来增加符号求解时可独立接入服务，但当前工具不宣称做了符号证明或精确求根。

长期记忆继续保存用户偏好和学习情况，不保存可执行绘图逻辑，也不因看过图像而自动提高掌握度。数学可视化能力随应用安装长期存在，属于 Skill 和工具能力。

## 支持范围

- 显式函数 y=f(x)，定义域 min/max；分段函数以多条曲线表达。
- 参数曲线 x=x(t)、y=y(t)：圆、椭圆、抛物线、双曲线两分支、旋转后的曲线。
- 隐式曲线 F(x,y)=0：网格与二分求根的数值等值线，检查残差，拒绝将分母极点误画成零点。
- 运算 `+ - * / ^`，括号，`sin cos tan sqrt abs ln log exp`，常量 pi/e。乘法必须显式，三角函数用弧度，ln 为自然对数、log 为常用对数。未知变量、脚本、隐式乘法、任意 LaTeX 不交给代码执行。
- 本界面 slider 的 id 作为公式参数。数学变量 x/y/t、常量和函数名称保留，滑块不能同名。
- 每图最多 6 曲线、20 固定标注；每公式最多 256 字符、96 节点、16 层。视窗和参数范围有上限。
- 默认等比例坐标，避免圆形失真。每条显式/参数曲线 1201 个采样位置；隐式图使用 100×100 网格，边界根二分 24 次。
- 隐式采样在 Flutter 后台 isolate 中计算，80ms 合并快速变更，用版本标记丢弃过时结果；显式/参数采样缓存于组件状态，不因普通页面重建重复计算。

## 消息协议

复用 version 3 InteractiveSurface，新增 type=`math_plot`：

```json
{
  "version": 3,
  "title": "椭圆与直线",
  "components": [
    {"id":"k","type":"slider","label":"斜率 k","min":-2,"max":2,"value":1},
    {"id":"plot","type":"math_plot","xMin":-5,"xMax":5,"yMin":-5,"yMax":5,
     "curves":[
       {"kind":"parametric","label":"椭圆","x":"3*cos(t)","y":"2*sin(t)","min":0,"max":6.283185307179586},
       {"kind":"function","label":"直线","expression":"k*x+1"}
     ]},
    {"id":"go","type":"button","label":"按当前斜率分析","action":"continue"}
  ]
}
```

工具参数 `definition` 为上面 JSON 的字符串。工具输出沿用 kind=`interactive_surface` 和定义哈希 revision，附 material_id 与 PNG Document 部分。当前控件状态保存于会话工具 metadata，原始定义不改写。PNG 是生成时默认参数快照；拖动滑块不修改已交付文件，界面明确说明。

## 使用与边界

发图片或文字题并请求讲解即可，匹配场景时模型自动读取 Skill、生成图像。是否触发仍由模型判断，不能承诺任意模型每次都会选对；图像输入要求模型支持视觉，生成要求工具调用能力。模糊照片、复杂手写题、所有供应商与 Mate 50 真机应继续单独验证。

图像是数值辅助，不是精确证明。采样无法保证捕捉极窄、高频或退化结构；隐式曲线可能漏掉小于网格的闭环、偶重根和歧义鞍点。标准圆锥曲线优先参数表示。固定 points 不随参数变化，Skill 要求只标真正固定且已推导核对的坐标。超出能力时说明限制，不伪造成功。

复验与证据见 [本轮自审报告](../qa/math-visual-20261010/report.md)。
