# 图片样式与个人模板交付

日期：2026-10-11，Asia/Taipei。

## 实现

- 图片库继续展示个人作品，“创建图片”打开独立创建页。顶部自由输入，下方六种样式，再展示用途与个人模板。聊天附件保留原创作输入；回答操作区新增“用这些内容制作配图”，填入该回答的文本并保留来源会话。
- 六种样式：写实摄影、电影感、扁平插画、水彩、3D 微缩、纸艺。每种使用独立原创 PNG，已逐张检查。空草稿选择样式填入对应示例描述；已有内容选择样式保留主题并更新视觉风格。选择不会发送生成请求。
- 四种用途：海报、头像、文章配图/封面、产品展示。填写必需主题、可选短文字、比例，生成可编辑草稿；参考图从原有输入框添加。全部继续使用单张生成和用户选择的质量。
- 成功图片在聊天卡片和全屏查看中均可保存为个人模板。模板编辑器保存名称、可替换的 `{主题}`、风格/构图约束、比例、质量。默认参考所选版本及之前成功版本的描述，明确将原主体和文字替换为新主题，用户可进一步整理约束。套用需填写新主题，填入草稿后才可手动生成。
- 模板支持列表、修改、确认删除、套用；Kotlin 将模板写入 `files/image_templates/<profile>/`，使用持久化写入和 UUID 校验，所有桥接检查档案和上下文版本。前端切档案后撤销创建页内容。模板不保存参考图片、凭据或历史请求 ID。
- 新页面沿用 StudyPalette，支持实时高亮色、深色、320px 大字体和系统减少动画。原点阵波纹加载组件保持不变。滚动浏览不销毁创作草稿或参考图，配置对话框控制器在退出动画后释放。

## 原创资源

由 Codex 内置 image_gen 生成，完整方形 1254×1254 PNG 直接放入 `client/flutter_ui/assets/image_styles/`，随 Flutter AAR/APK 打包；未使用应用的 apinode 凭据。六次独立生成，以设计质量为优先，没有请求经济质量。完整提示词和来源记录见 [original-style-prompts.md](ui-design/image-system-v1/original-style-prompts.md)。提示词驱动的模板复用不能保证主体或风格像素级一致，样例也不构成用户所选提供商的效果保证。
