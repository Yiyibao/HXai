# MathStudyAgent 网页 ImageGen 页面提示词

2026-10-07 更新：已按用户采纳的粉色角色、纯白背景、淡粉交互及输入框模型框生成 16 张前端页面图，新增模型选择与多提供商管理设计。[最终图片与页面清单](ui-design/white-pink-v1/README.md) · [本批实际提示词](ui-design/white-pink-v1/prompts.md)。下文绿色母提示词为历史版本，当前选稿使用新目录。

版本：v1.0，2026-10-06。用途：用户手动复制到网页端生成静态视觉参考。关联 [动效与页面专项](motion-design-reference.md) 及 [详细实现方案](implementation-plan.md)。本轮没有自动生成图片。

## 1. 使用顺序

1. 先用下面的 G00 生成原创伙伴方向，选择一个轮廓。工作代号“页芽”无需绘制文字，最终名字仍可调整。
2. 生成页面时复制 **统一母提示词 + 一段页面提示词**。每次只生成一页，避免整套页面挤在一张图中导致文字不可读。若网页支持参考图片，可附已选角色或页面图作为一致性参考。
3. 建议先做 P02 教学聊天，再做 P03 材料、P05 记忆、P08 成果预览；这四页确定主风格。其后补 P01/P04/P06/P07/P09/P10 与 FX-A 动效关键帧。
4. 中文或公式有错误时用文末修图提示，保持其他布局。画面只是草图，文字最终由应用实际排版；无需为了图像模型反复拟合长篇中文。

页面 ID、文件名称、学习内容和数量均为设计样例。模型名、能力、进度、保存结果等不能从这些图继承为真实产品事实。下列所有提示词可直接复制，拼接时无需加入实现方案全文。

## 2. G00：原创伙伴方向

```text
为 MathStudyAgent 设计一个原创、适合成人数学学习应用的小伙伴。生成一张清晰的角色设计参考板，横向约 1600×1000，白底，只有一个统一角色的正面与少量姿态，不要混合多个角色方案。

角色是一枚站立的折页书签：偏长纸片轮廓，一侧有不对称折角，中央一条细折痕，底部浅 V 形书签缺口，两枚小墨点眼睛，微小侧页用于表达动作。浅玉绿纸片、暖杏色折角、深墨绿细节。外形简洁，能用少量路径和形状重建，在 32–40 dp 的小尺寸仍可识别。优雅温暖，适合大学学习者，避免幼儿玩具、塑料和毛绒质感。

左侧放较大正面，右侧按一致尺度展示六个姿态：静候、专注阅读、组织讲解、等待核对、记录完成、遇到问题。阅读用小幅折页与视线变化，完成仅轻轻舒展，遇到问题平静收拢，不哭泣、不责备。姿态各自完整、互不遮挡，可加很小的中文标签；不加名称、口号、商品包装。

需要原创轮廓和原创表情，不复刻 Coucou/Mochi；不要灰白圆角团子、巨大球面眼睛、吞食文件、标志性旋涡表情，不使用现有角色、图标或品牌。仅是静态设计板，不是精灵图或实际动画。简洁的矢量感插画，轻柔纸张层次，避免逼真纸纤维和复杂光影。
```

## 3. 统一母提示词（每次生成页面都加上）

```text
设计 MathStudyAgent 的原生 Android 手机应用高保真 UI 静态参考稿。它是手机独立运行的数学学习 Agent，帮助学习者教学聊天、阅读材料、自动整理有来源的学习记忆、生成真实学习笔记。面向成人学习者，简体中文，温暖、可靠、安静，有阅读纸面的质感和克制的生命感。

输出单张完整竖屏页面，比例约 412:892，可用约 1080×2340 或最接近的竖屏尺寸。无手机外壳、无透视、无桌面背景、无海报标题、无解释箭头、无水印；页面边缘和底部操作必须完整。使用 Android 的系统栏与手势安全区域，顶部为状态栏和正常应用顶栏，不加入 iPhone 黑色灵动岛。按安全边距呈现，不绘制特定机型外壳或物理缺口。

布局可用 Kotlin/Jetpack Compose 和原生 Material 3 控件实现。背景 #F7F8F3，白色卡片 #FFFFFF，主色玉绿 #2F6E60，正文墨色 #202C29，次正文灰绿 #5D6963，浅分隔 #E3E9E3。暖杏用于待核对，暗红只用于真实操作失败。大留白、细边线、很浅阴影；卡片圆角约 16–20 dp。中文正文视觉对应约 16 sp，层级清楚，禁止大量小字、荧光渐变、厚重玻璃模糊、3D 设备展示。按钮有至少 48 dp 的触摸空间；正文与公式的可读性高于装饰。

主页面固定四个底部入口，顺序“聊天、材料、记忆、成果”，当前入口有清楚选中态；设置在顶部菜单。详情或弹出面板按单页提示决定是否显示主导航。教学方式用一个小选择器“引导学习”，不要常驻四个大按钮；其他方式为给我提示、检查步骤、完整讲解。历史、Skills、连接参数是次级入口。不要加入计划日历、正式掌握度、考试倒计时、积分排行榜、多 Agent 面板、终端或桌面悬浮球。

顶部只有一个原创折页书签伙伴：偏长浅玉绿纸片、一侧不对称暖杏折角、中央细折痕、底部浅 V 形缺口、两枚小墨点眼睛、微小侧页。视觉尺寸约 32–40 dp，不在每条消息重复出现。若附了已选角色或页面参考图，严格保持其形状、配色、笔画和导航。禁止复刻 Coucou/Mochi 的角色、图标或素材。

所有示例中文尽量准确。只画单页提示明确要求的文案和公式，不要补长篇答案、伪造数据或乱码段落。示例状态都是设计演示：不把“正在生成”画成已完成，不显示假百分比、假计时、已掌握或已验证标签；保存与导出成功只在单页明确指定成功状态时出现。声音默认关闭。
```

## 4. P01：聊天空态

```text
生成聊天首页空态，底部“聊天”选中。顶部标题“MathStudyAgent”，左侧历史会话入口，右侧小伙伴和更多菜单；当前学习者示例为“小林”，不突出多人管理。

正文以“从一个问题开始”为标题，下面一句“拍一道题，或说说你卡在哪一步。”伙伴只在顶栏出现，正文不重复；不要大型吉祥物宣传页。放三个清楚的快捷入口“拍题”“选文件”“继续上次讨论”，下方一条近期会话“函数定义域 · 上次停在分母条件”，空间留给输入。

底部输入区域为附件按钮、输入框“输入题目或你的想法”、发送按钮；输入框上方有小选择器“引导学习”。未输入时发送按钮体现未启用状态。此图是假设连接已配置的普通空态，不展示模型名称、连接成功、学习时长或累计成绩。
```

## 5. P02：教学聊天（主风格锚点）

```text
生成真实教学聊天页面，底部“聊天”选中。顶栏为“函数定义域”，小字当前档案“小林”，原创书签伙伴为专注姿态。顶部短状态胶囊“正在生成讲解”，没有百分比或计时。

页面呈现短对话：用户题卡中的公式以正规的数学排版显示 y = sqrt(x−1)/(x−2)，尽量绘成分式，根号只覆盖 x−1。用户消息“我得到 x>1，对吗？”助手回复两句：“先看根号内：x−1≥0，所以 x≥1。”“再检查分母：哪些值会让它等于 0？”不把答案完整泄露，不加已掌握或已验证徽章。

底部输入框“写下你的下一步”，旁边稳定可见“停止”按钮；上方小选择器“引导学习”。提供轻量的“给我提示”入口但不放四个大模式按钮。大部分空间用于题面和讲解，公式和正文清晰，不把状态、思维链或工具日志展开成长面板。小伙伴不重复出现在消息头像中。只展示生成中的静态瞬间，不加运动模糊或漂浮粒子。
```

## 6. P03：材料列表与部分处理

```text
生成材料页，底部“材料”选中。标题“材料”，右侧“添加”按钮和小伙伴，顶部一行轻量筛选“全部 / 图片 / 文档”。

列表第一张卡“函数讲义.pdf”，PDF图标，示例“12 页”。真实展示阶段为“已处理 1–3 页，其余未处理”，小字“当前选择的阅读范围”；提供“查看已处理页”“选择其他页”。不要画成全部读完或加 25% 进度条。

第二张卡为题图缩略图“手写题.jpg”，暖杏标记“1 处符号待核对”，按钮“核对原图”；第三张卡“课堂笔记.docx”，状态“待处理”，不写 Word 页码。

顶部可有一条接收文件的静态状态“已接收，等待处理”，但不同时显示正在分析整个资料库。原图缩略图和文件名完整可见，卡片清楚表达实际范围。没有向量数据库、OCR协议、token或解析版本等开发字段。
```

## 7. P04：原图核对底部面板

```text
生成教学聊天页上的符号核对底部面板，面板占约屏幕下方三分之二，背景聊天适度变暗。底部主导航被面板覆盖，不露出与核对冲突的操作。

面板标题“请核对这个符号”，顶端有轻量拖动条，原创书签伙伴为安静等待姿态。上方展示一段清楚的手写题图裁剪，矩形标出疑似“x−2”或“x+2”的分母区域，其他内容弱化但原图可回看。说明“这里的符号还不确定，请以原图为准。”

下面提供两个大选项“x−2”“x+2”，以及“手动输入”。两个选项默认都未选中，“确认并继续”按钮未启用；旁边有“稍后处理”文字按钮。不要把推荐答案预选成识别结论，不展示识别完成或成功庆祝。字号可读，操作区域宽裕，问题不会因角色动作消失。
```

## 8. P05：学习记忆列表

```text
生成记忆页，底部“记忆”选中。标题“学习记忆”，小字“当前档案：小林”，右上更多菜单；一个安静的原创书签伙伴。顶部显示“自动记忆已开启 · 管理”，这是设计样例中的开关状态，不展示累计掌握度。

展示三张简洁条目卡：
1. “喜欢先看反例”，来源标记“你明确告诉我”，状态“已保存”；
2. “本轮给出的定义域未列出分母限制”，来源“自动整理 · 今天的对话”，证据标签“一次观察”，状态“已保存”；
3. “正在学习函数”，来源“自动整理”，状态“待核对”，暖杏色处理，与前两条分开。

每条有可进入详情的箭头；事实、来源、状态容易区分，不出现‘经常出错’‘已掌握’等扩大推断。页面底部附近可有一条轻量通知“已新增 1 条学习记忆 · 查看”，这是成功事务后的静态设计样例，不遮挡列表，通知消失后条目仍可打开。没有学习雷达图、正式进度和分数。
```

## 9. P06：记忆详情与来源

```text
生成“记忆详情”子页面，顶部返回按钮，不显示底部四主导航。主卡事实：“本轮给出的定义域未列出分母限制”。下面分列“来源：今天的函数定义域对话”“类型：一次学习观察”“后续作答：未验证”，文案短而清楚。

来源区显示用户原话“我得到 x>1，对吗？”以及助手提示“再检查分母：哪些值会让它等于 0？”，用引用卡片呈现，按钮“回到原对话”。只展示该档案的示例证据，不编造跨会话次数或正确率。

页面有温和说明“这是本次讨论的观察，不代表正式掌握度。”底部稳定操作为“更正这条记忆”和次级“删除”；删除不是巨大的红色主按钮，不展示已删除仍保留的敏感正文，也不额外添加自动撤销。伙伴很小或不出现，证据文字优先。
```

## 10. P07：成果列表

```text
生成成果页，底部“成果”选中。标题“学习成果”，顶部次级筛选“全部 / 笔记 / 总结 / 练习”，右侧可有“新建”文字按钮。

用文件类型、小缩略图和整齐卡片构成页面，草稿与实际文件清楚区别；不要把所有草稿都画成可下载成功文件。没有自动同步 MathStudy 的成功标签，没有云端公开链接、正式错题入库或考试成绩。
```

## 11. P08：笔记预览与 PDF 导出成功

```text
生成“笔记预览”子页面，顶部返回和“编辑”，不显示底部四主导航。主体是可读的纸面笔记预览，标题“函数定义域学习笔记”，小字“草稿版本 v2”，内容仅两条：“根号内需非负：x−1≥0。”“分母不能为零：x−2≠0。”下面一条公式“定义域：[1,2)∪(2,+∞)”，符号正确、留白充足。来源区“来源：函数定义域对话”，可回看。

底部固定操作面板明确显示设计样例中的真实成功阶段：“PDF 已生成并校验”；文件名“函数定义域学习笔记.pdf”，版本“来自草稿 v2”，动作“打开文件”“分享”。原创书签伙伴在成功标签旁轻轻舒展的静态姿态，面积很小。成功只表示导出文件完成，不表示数学工具验证或学习者掌握。

格式选择仅“PDF / Markdown”，不显示 Word，首版 Word 能力仍未确认。不要画假的文件大小、页数、下载网址或已发送给别人。分享按钮表示用户可打开系统分享，不是已经分享成功。
```

## 12. P09：设置与减少动画

```text
生成设置子页面，顶部返回按钮和标题“设置”，不显示底部四主导航。以原生分组列表呈现，不展示工程控制台。

“模型连接”分组：连接配置入口、密钥字段只显示圆点、“测试连接”按钮；不预先显示测试通过，不使用真实服务器地址或 API 密钥。
“学习档案”分组：当前档案“小林”，一个进入管理的列表行。
“记忆与材料”分组：自动学习记忆开关为开启，说明“保存有来源的学习观察，可查看和更正”；材料管理入口。
“显示与动效”分组：减少动画开关为开启，说明“静态显示伙伴，保留全部状态和操作”；主题“跟随系统”，不加尚未实现的服饰或音效商城。
“数据与技能”分组：备份与恢复入口、教学 Skills 入口。只展示入口，不画尚未验证的加密方式、云同步成功或精确备份进度。

大字号和宽触摸区，不放大量版本、协议、token和隐藏开关。原创伙伴静止，只在一个分组附近小尺寸出现。
```

## 13. P10：错误与恢复状态参考板

此项是用于对照的横向状态板，覆盖母提示词的单页竖屏输出限制；只生成三张等宽局部界面，不挤入完整十页。

```text
生成 MathStudyAgent 的错误与恢复 UI 参考板，横向约 1800×1100，三列等宽、相同色板和控件样式，各列是清楚的手机页面局部，不要手机外壳。顶部小标题“状态设计样例”，各列有足够留白和可读中文。

第一列“连接中断”：聊天中已收到的两行讲解保留；静态状态卡“连接中断，已保留收到的内容”，按钮“重新生成”，次级“检查连接”。没有无限转圈和假倒计时。
第二列“记忆未保存”：提示“本次整理未保存，请稍后重试”，按钮“重试”，次级“查看已有记忆”；不画已新增或删除已有条目的成功标记，不责备用户。
第三列“导出完成，分享已取消”：本地文件卡保留，“PDF 已生成”，按钮“打开文件”“再次分享”；不显示已发送、文件损坏或要求重新生成。

原创折页书签伙伴三列统一，失败时平静收拢，完成时静候；关键状态由文字和图标表达，不能仅靠颜色。禁止哭泣、强烈红屏、弹窗层叠、运动模糊和悬浮粒子。只是静态状态对照，不是真实运行截图。
```

## 14. FX-A：动效关键帧板

```text
为 MathStudyAgent 生成一张原创折页书签伙伴与材料卡片的动效关键帧参考板。横向约 2000×1300，三行，每行四帧，白底，严格保持同一角色轮廓、尺度、笔画与配色。角色为偏长浅玉绿书签，一侧暖杏折角，中央细折痕，底部浅 V 缺口和小墨点眼睛。不要使用 Coucou/Mochi，不复制其吞食或大眼球动作。

第一行“接收材料”：文件缩略图在输入区域；缩略图短距离靠近材料卡；书签折角轻收拢；材料卡稳定显示文件名。文件始终存在，没有消失吞食。
第二行“等待核对”：静态状态胶囊；胶囊展开；原图与选择按钮出现；卡片停留且按钮清楚。角色视线轻转向卡片，不持续弹跳。
第三行“记忆保存”：处理中姿态；事务成功的示意节点；书签轻轻舒展；静态文字“已新增 1 条学习记忆 · 查看”。每帧同一空间锚点，幅度克制，正文不变形。
```

## 17. 选稿检查表
