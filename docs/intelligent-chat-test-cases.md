# 智能Chat测试用例

## 测试准备

1. **构建APK**
```bash
cd client
./gradlew :app:assembleDebug
```

2. **安装到模拟器**
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

3. **配置API密钥**
   - 打开应用
   - 进入设置
   - 配置OpenAI/Claude/Gemini API密钥

---

## 测试用例1: 数学函数探索

### 用户输入
```
帮我理解二次函数 y = ax² + bx + c 的图像变化
```

### 预期行为
1. AI调用`create_interactive_surface`工具
2. 生成包含以下组件的界面:
   - 3个滑块(a, b, c参数)
   - 1个折线图(函数曲线)
   - 1个说明卡片
   - 1个"继续讲解"按钮

### 验证点
- ✅ 界面正确渲染
- ✅ 滑块可以拖动
- ✅ 图表根据滑块实时更新(本地计算)
- ✅ 点击按钮后触发新对话

### 操作步骤
1. 调整a=2, b=1, c=-1
2. 观察图表变化
3. 点击"继续讲解"按钮
4. 验证AI收到状态: `{"a_param": 2, "b_param": 1, "c_param": -1}`
5. 验证AI基于新参数继续讲解

```
| 月份 | 地区 | 销售额 |

| 1月  | 上海 | 150万  |
| 2月  | 北京 | 135万  |
| 2月  | 上海 | 180万  |
```

### 预期行为
1. AI生成交互界面:
   - 地区选择器(全部/北京/上海)
   - 数据表格(支持筛选)
   - 柱状图(销售趋势)
   - "深入分析"按钮

### 验证点
- ✅ 选择器切换时表格自动筛选
- ✅ 图表正确显示数据
- ✅ 状态正确保存和恢复

```json
}
```

### 快速验证
- ✅ 界面显示

- ✅ 按钮点击触发对话

## 调试技巧

### 查看工具调用
在logcat中搜索`CreateInteractiveSurface`查看工具参数

### 查看状态保存
```bash
adb shell run-as me.rerere.rikkahub cat shared_prefs/interactive_surface_states.xml
```

### Flutter调试
```bash
flutter logs | grep "Surface"
```

### 手动触发工具
在Kotlin代码中直接调用:
```kotlin
val tool = CreateInteractiveSurfaceTool()
val result = tool.execute(jsonArgs)
```
