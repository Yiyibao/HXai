# S3 教学闭环

2026-10-07。用户本轮五项要求优先于旧阶段表：S3 现指诊断、分层练习、学习记录、进展与闭环验证。旧 S3 的材料分块和 Skills 导入另列待办，不因本轮完成而宣称已交付。

## 诊断与练习

`StudyLearningLoop.prompt` 在 GenerationLoop 请求组装时加入，覆盖既有助手和四种教学模式。当前问题、具体作答、学习背景与有效历史错因是诊断依据；历史错因不证明本轮错误。无充分证据先用短题确认。给基础辨析、同型应用、迁移检验三个层次，提示按概念、关系、局部步骤逐级推进，必须等待用户新作答。完整讲解仍服从用户当次要求。

教学由模型在聊天中执行，不使用关键词自动判定数学答案正确，也没有独立的题库或评分器。提示等级体现在对话正文，不宣称数据库保存了确定的逐题正确率。真实教学文本须另作数学与教学核对。

## 实际作答与更新

沿用 S2 的按档案存储、应用签发来源、增量任务、事务、人工修订优先和删除抑制。模型答案不得作为本人学习事实。抽取规则保留多次作答，每次表现的事实键包含用户来源 ID；仅阅读、提示后作答、独立尝试分别记录，不表示正式掌握度。相同文字但不同证据等级不再去重合并。明确记住的 PERFORMANCE 也保留为 CANDIDATE；用户要求记住不等于数学结果已被验证。

复习事项只从用户实际提出的请求记录。模型建议不能伪装成用户已接受的任务。新复习作答新增证据，不自动删除旧错因；没有作答不标记完成。本期不增加正式掌握度评分、任务完成勾选或独立复习日历。

## 进展

记忆页新增学习进展卡，分为当前卡点、近期作答证据、下一步复习事项。每组最多五条，按更新时间展示，保留候选标签、证据等级和来源时间；可回到原会话，下方记忆详情可查看原消息。空数据明确说明暂无记录，冲突和来源失效不显示为进展。切换档案重建页面与订阅。

## 可复现验证

运行 `scripts/test_s3_completion.ps1`；加 `-RealModel` 使用模拟器既有连接，进行错误→提示→重答→独立尝试→阅读反馈→复习建议的真实聊天并抽取记录，不读取或输出密钥。测试仅修改指定模拟器，创建独立 QA 档案，结束后恢复原设置并删除 QA 数据。

JVM 测试检查证据分级、失效/冲突过滤和不同等级不合并。Android 测试检查真实 Room 提交、应用签发来源、幂等、重开数据库、两人隔离、删除抑制、来源失效与明确记住的表现不进入事实检索。页面回归覆盖进展入口、原始来源、更正、删除与档案切换。

真实模型样例与模拟器结果见 `qa/s3`。模拟器不替代 Mate 50 验收，数据库重开不冒充新的跨进程测试；S2 已有跨进程验证，本轮沿用其存储结构。
