## 3. S2 自动记忆

| ID | 场景 | 通过条件 |
|---|---|---|
| M01 | “记住我喜欢先看反例” | 真正写入明确记忆并反馈；新会话可找回；失败不说已保存 |
| M02 | 完成学习后不说“记住” | 达到触发条件后自动产生有来源的条目；重启后仍存在 |
| M03 | 同一批重试三次 | 条目和证据不重复；游标只在成功时推进 |
| M04 | 零候选、短会话、任务结束 | 无事实时不虚构；短会话结束仍可抽取，不机械等待长时间 |
| M05 | “不是我，是教材里的人”及假设题 | 不把材料作者、假设角色或模型答案保存为本人事实 |
| M06 | “我懂了”、提示完成、独立尝试 | 保留准确证据级别；不自动变成已掌握或正式分数 |
| M07 | 同一错误一次与多次 | 单次记录不写“经常”；重复记录引用不同有效学习来源 |
| M08 | 用户明确更正旧背景 | 当前事实更新；旧条目失效或保留为历史；摘要和缓存同步更新 |
| M09 | 人工编辑后旧任务提交 | 检查 revision；不会覆盖人工修订 |
| M10 | 自动抽取跨人或虚构来源 | 拒绝提交；日志只保留必要错误类型，不泄露其他人的正文 |
| M11 | 新会话相关检索 | 命中当前人的相关事实；没有相关事实时不硬凑画像 |
| M12 | 中文同义词和数学主题 | 固定别名/主题样例有效；结果带时间、来源并能回看 |
| M13 | 删除后重跑同一旧聊天 | 删除条目不会重建；摘要、缓存与模型历史读取均排除相应内容 |
| M14 | 删除时抽取请求已在途 | 返回后提交检查 delete_epoch；不会写回已删除事实 |
| M15 | 同义改写、旧分支与摘要重建 | 固定删除反例集不重建；发现无法拦截的类别记录并修正规则 |
| M16 | “重新记住” | 只有新的明确用户来源可重新启用，自动抽取不能撤销删除 |
| M17 | 删除原始消息或修改题面 | 相关证据失效；不继续把识别错误或旧版本当成有效学习表现 |
| M18 | 关闭自动记忆、重新打开 | 关闭后无后台抽取提交；保留历史管理能力；重新开启按规则补处理 |
| M19 | 30 组人工标注评估 | 事实精确率 ≥95%、应记事实召回率 ≥85%；串人、虚构来源、关键更正被覆盖为 0 |
| M20 | 检索预算、队列与聊天优先 | 记忆有界；不挤掉当前题目关键条件；整理不明显阻塞问答 |

M19 需另列事实条目级的 TP/FP/FN 和分母；30 组是初始样例规模，不是统计泛化保证。每个错误保留原始样例及人工判定；不能由抽取模型自己给自己打分。
