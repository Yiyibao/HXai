## 🔍 自动配图功能说明

根据您的要求，图片功能的设计思路是：

### 当前实现状态
✅ **UI 展示层完全就绪**：
- 图片元数据完整支持
- 全屏查看和追问功能
- 来源标识和链接
- 失败占位处理

### 数据流接入
需要在 AI 回答生成时：
1. 当检索到网页资料时，提取网页中的相关图片
2. 按段落意图选择 1-3 张最相关的图片
3. 将图片 URL 和元数据保存到消息 parts
4. Flutter 端自动使用 EnhancedImageView 渲染

### 元数据格式示例
```dart
UIMessagePart.Image(
  url: "https://example.com/image.jpg",
  metadata: {
    "caption": "极光在大气层中的光学现象",
    "sourceUrl": "https://science.nasa.gov/...",
    "author": "NASA",
    "sourceType": "web_search",
    "order": 1
  }
)
```

### 实现路径
1. 检查 MaterialTools 或搜索工具是否支持网页图片提取
2. 在生成回答时，调用图片提取逻辑
3. 按相关性选择图片（1-3 张）
4. 将图片插入相关段落附近
5. Flutter 端自动渲染（已完成）
