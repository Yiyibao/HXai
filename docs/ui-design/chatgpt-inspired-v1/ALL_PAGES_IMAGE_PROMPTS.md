# 全页面 Image 生成提示词：已采纳 ChatGPT 风格

日期：2026-10-09。适用：网页端 Image 逐页生成本项目剩余设计稿。**本文件提供提示词，不代表页面已实现。**

## 使用方式

1. 建议新建一个专门的图片生成对话，先上传用户已采纳的基础两页图 `two-page-preview.png`。它是最高优先级视觉参考。
2. 需要图表或参数组件时，可以再上传 `smart-chat-three-scenes.png` 作为内容层级参考；它不能覆盖基础参考图的输入框与总体风格。
3. 需要图文页面时，可以上传 `image-chat-mobile.jpg` 作为真实布局参考。其顶部四个场景切换按钮属于预览工具，正式页面不要画；该图的照片是真实 NASA 来源，其他生成页面中的照片必须标注“配图示意”。
4. 从本文件任选一页，将该页代码块**整段复制**到网页端 Image；每段已包含统一风格，不需要另行拼接总提示词。每次只生成一页。
5. 新开图片对话时重新上传基础参考图。连续生成时保留同一参考图，发现风格漂移就重新附图。不要上传旧白粉16页作为当前风格参考。
6. 将生成结果按编号保存，例如 `P01-history.png`。文字、状态和来源需要人工检查；图片只能展示外观，不能证明点击、文件处理或连接成功。

### 一致性纠偏提示词

某页风格漂移时，上传该页为编辑目标、基础两页为风格参考，使用：

> 请编辑这张页面图，只统一视觉，不改变当前页面信息与状态。严格匹配另一张已采纳参考图的白底、黑灰文字、浅灰气泡、圆角输入框、单色线性图标、字体和留白。去掉粉色主视觉、渐变、吉祥物、装饰性大卡片和额外底部导航。统一控件圆角、字重和边距；次级页使用返回箭头，聊天页保留输入框内模型按钮。保持全部中文可读，不增删功能，不把处理中画成成功。只输出一张完整竖屏页面。
