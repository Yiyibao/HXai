## 3. 尚未完成的功能

### 3.1 图片功能增强

根据交接文档第 4、5、6 节，以下图片相关功能需要进一步实现：

#### 未完成项：
- ⚠️ **自动配图检索**：用户询问"极光为什么有不同颜色？"时，系统尚未自动从网络检索 1-3 张相关图片
- ⚠️ **图片元数据**：需要保存图片 ID、来源 URL、图注、作者/机构、日期等完整信息
- ⚠️ **图片展开全屏**：点击图片后全屏查看，显示完整图注和来源链接
- ⚠️ **针对图片追问**：需要携带图片 ID 和上下文进行后续提问
- ⚠️ **图片来源标注**：每张图显示原出处和可追溯的来源信息
- ⚠️ **图片加载失败处理**：稳定占位，显示图注和原出处链接

#### 数据层需求：
```dart
// 需要扩展 UIMessagePart.Image 的 metadata 字段
{
  "imageId": "unique_id",
  "sourceUrl": "https://...",
  "sourceType": "web_search" | "user_upload" | "ai_generated",
  "caption": "中文图注",
  "author": "作者/机构",
  "publishDate": "2024-12-19",
  "altText": "备用文本",
  "order": 1  // 在回答中的顺序
}
```

#### 实现路径：
1. 检查现有搜索工具（`MaterialTools.kt`）是否支持图片检索
2. 在 AI 回答生成时，根据段落内容选择 1-3 张候选图片
3. 将图片插入到相关段落附近
4. 保存完整的图片元数据
5. 实现图片展开界面（使用 Navigator 或 Dialog）
6. 实现"针对这张图追问"的输入入口
