# 智能 Chat 视觉板生成提示词

内置 image_gen；三页视觉参考，示例内容。

Use case ui-mockup. Design a premium high fidelity proposal board containing THREE complete mobile chat app screens side by side for MathStudyAgent, a general personal AI agent. This follows an accepted ChatGPT-inspired white/black/gray minimal mobile style. Wide canvas ~1900x1250. Light gray board background, flat white screens, NO device hardware or perspective. Each screen full height with 9:41 status, hamburger upper left, "Chat" with chevron top center, compose icon upper right, white background, black body text, gray secondary typography, rounded light gray user bubbles right aligned, assistant on plain white. Consistent bottom anchored light gray composer with plus, model pill "当前模型" dropdown, black circular send arrow, footer "AI 的回答可能有误，请核对重要信息". Chinese system font and crisp typography. Tiny board labels above: "01 / 文件与成果", "02 / 交互式分析", "03 / 参数探索". No colorful dashboards, avatars, mascot, gradients, bottom tabs or apps branding. Primary actions monochrome black. A restrained muted slate blue is allowed ONLY for graph data lines, no colored card backgrounds. Limit each interactive card to two main actions; no internal scrollbars, no tabs, no duplicated chat textbox inside card. Goal show intelligent interactive answers integrated naturally into chat.
