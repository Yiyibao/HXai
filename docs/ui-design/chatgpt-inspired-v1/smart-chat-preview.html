DISPLAY PRINCIPLES

内容决定展示方式

图片靠近它解释的段落

通常 1–3 张。每张图都有解释任务，不重复、不靠堆图营造丰富感。

来源随内容走

配图显示原出处与图注，正文引用紧贴结论。检索照片与生成示意图明确区分。

轻量内容留在对话里

一张卡片解决一个操作问题；复杂内容点开全屏，保留追问入口。

操作即时，提交明确

筛选、点选和滑块先在本地更新。点击“分析”或发送消息，才继续对话。

进度来自真实任务

步骤可展开；失败保留已完成内容。没有确定进度时不显示虚构百分比。
