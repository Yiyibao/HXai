# 前端交付与复审修复

更新日期：2026-10-08（Asia/Taipei）。本文件取代 Gemini 原先“P01–P16 全部完整交付”的结论。

本轮按审查顺序修复六项问题：

1. P12 / P13 正式路由改为 `StudyProviderPage` / `StudyProviderDetailPage`，P14 从列表及详情页均可进入。高级设置保留在 `Screen.SettingProviderAdvanced`，多类型配置复用原有 `ProviderConfigure`。
2. 删除 `delay` 加 URL 前缀判断的模拟成功逻辑。连接检查调用已有 `ProviderManager.listModels`；显示模型列表请求结果，配置修改时清除结果并取消请求，版本校验拒绝迟到响应。凭据保持遮蔽，错误提示不回显原始异常或密钥。
3. 记忆编辑使用打开编辑器时的 revision；后台变更不覆盖草稿，冲突在弹窗内提示。草稿与编辑版本支持保存恢复；保存期间阻止重复提交。
4. 一次性反馈使用 SharedPreferences 同步持久化事件身份摘要，先记录再反馈。历史快照首次加载保持安静；进程重启不再仅依赖内存集合。
5. 模型选择等待设置写入成功后关闭抽屉；失败显示错误并保留原选择，保存期间禁用重复选择和管理跳转。
6. 契约测试直接调用生产分组、恢复状态映射和保存逻辑。新增持久化恢复、写入失败、异步等待、取消与真实记忆编辑版本冲突测试，并补充 Android 界面回归。

同时修正新提供商默认注入指定模型及未经验证能力的问题：新增提供商从空模型列表开始。提供商列表和模型管理写入增加异常提示、重复提交防护，并基于当前配置修改模型列表。
