# Pro review source increment v1.2 — native admission slice

2026-10-12, Asia/Taipei. Original `HXai_Pro_Delivery/10_REVIEW_SYSTEM/` v1.1 files are preserved byte-for-byte. This increment adds applicability/source mapping; it does not reduce any original gate. Base is 5d826d5d7d8755ed42db834d6cd6dc52ae914c69, local branch codex/pro-agent-model-phase2. Final source hashes/HEAD are in SOL_IMPLEMENTATION and review evidence.

Native task persistence is now `feature/agent/AndroidAgentTaskPersistence.kt`, AtomicFile sidecar schema 1 in noBackup, shared across profiles. It is neither Python schema 2 nor a Room migration. Room stays v32; serialized PendingInput gains nullable modelLock and UIMessage gains nullable local agentTaskId. Queue/message columns remain existing JSON. Unknown/future/corrupt sidecar data is rejected without recreation. References unavailable after cross-device backup restoration block execution rather than silently selecting a new model.

Task states are QUEUED/RUNNING/WAITING_AUTHORIZATION/PAUSED/UNCERTAIN_SIDE_EFFECT/RESPONSE_READY/NEEDS_VERIFICATION. There is intentionally no native SUCCEEDED state until independent goal predicates and trusted tool verifiers exist. Returned transport/tool payload hashes are metadata, not verified artifacts or proofs. The native slice does not yet implement the entire Python grant/blocked_on/plan protocol.

All ChatService launchGenerationJob callers wrap the original executor with AgentScheduler; the scheduler holds both a coroutine mutex and OS execution lease. Persistent fence and slot gate claim/publication. Stop/restart cannot release an unknown provider/tool request; OS lock acquisition alone is not evidence that remote effects did not happen. Predecessor joins happen before acquiring the global slot. Queue edits must distinguish trusted explicit intent revision from idempotent request replay.

Provider journal records main and context_summary request identity before dispatch. Snapshot disables blind automatic network retry; no financial hard budget is introduced. Legacy SDK zero counters without provenance are conservatively unknown/null. Title/OCR/image/translation/memory role authorization and usage remain separate required work. Frozen credentials may not bypass removal/disable/credential changes; rotation recovery is blocked pending AUTH-03.

Required new gates: cross-conversation/profile claim, immutable encrypted selection and reasoning after Settings edits, stale fence, duplicate call rejection, unknown slot retention, valid legacy input preservation, explicit queue revision, lost return ACK, future schema preservation, native AtomicFile/vault/OS lease and cross-process artifact preservation. Native tests use a separate org.hxsi.agent.phase2qa.debug package and synthetic localhost transport. Production, paid model, Mate50, Release and professional action-task verification are separate gates.

The original v1.1 source map remains historical; current paths/line numbers and applicability are in HXai_FULL_REVIEW/SOURCE_TRACE_MATRIX.md and HXai_CHANGE_REVIEW/AGENT-01-MODEL-02/TRACE_AND_DIFF.md.
