# 手机诊断与反馈

2026-10-07：在现有核心功能基础上增加，无须手机连接电脑。

## 使用

1. 出现问题后进入 **设置 → 诊断与反馈**；崩溃后进入的安全模式也有同一入口。
2. 填写发生时间、操作步骤、预期/实际结果，注明是否锁屏、切后台或断网。最多 2000 字，可不填写。
3. 选择 **保存诊断包**，在系统文件选择器中选择位置；完成后会重新读取文件并核对 SHA-256。也可选择 **分享诊断包**，再自行选择接收者。
4. 截图/录屏另外发送。分享面板打开不等于成功发送；应用不会自动上传诊断包。

请不要在复现说明中填写 API 密钥。手动填写的文字原样进入反馈文件；自动记录不包含聊天、模型请求/响应正文、网址、头、材料文件名、档案身份、数据库或凭据。

## 诊断内容

- `report.json`：报告编号、版本/包标识/构建类型、设备/Android API/ABI、可用空间、系统运行时长（非应用使用时长）、内存等级、最多 200 条事件、最近一次崩溃。
- `feedback.txt`：用户手动填写的复现说明。
- `README.txt`：内容与能力边界。

事件使用固定枚举，只接收随机本地操作编号、HTTP 状态码、耗时。记录启动、前后台、共享 HTTP 客户端及文档服务网络请求、响应体读取失败、聊天生成、材料写入任务、文档操作、备份生成与恢复预校验。文档后台重试/远端 FAILED 和启动恢复失败也会记录。HTTP 收到响应、正文读完和业务完成是不同阶段；提前关闭响应体标为 CLOSED，确认调用取消才标为 CANCELLED。

崩溃仅保留异常类型和最多 40 个项目代码栈帧，不存异常消息、cause、文件名或线程名。记录在独立 noBackup 目录中同步原子写入，安全模式清除旧提示时不会删除诊断记录。其他事件在单线程后台队列中原子写入，进程骤停可能丢失队尾事件。导出前等待已排队事件完成。

## 存储与边界

- 单个元数据文件读取/写入上限 128 KiB；事件滚动保留 200 条，崩溃保留最近一次。
- 本地临时 ZIP 保存于缓存独立子目录；下次导出清理超过 24 小时的包，同时最多保留 30 份。
- **清除本机诊断记录**需要确认，会删除元数据和临时 ZIP，不影响学习数据。不会删除已经另存/分享的副本。
- 无自动遥测、系统 logcat 读取或云端反馈提交；本地操作编号不是服务器任务编号。
- 不覆盖原生崩溃、系统 ANR、所有工具/第三方客户端或厂商进程终止原因。没有记录不能证明没有故障。
- 设备系统字段采用 Android 公开属性，不保证自动识别 HarmonyOS 完整构建版本；反馈时可附手机系统设置截图。
- 模拟器通过不替代 Mate 50 的安装、文件提供器和分享应用验收；当前构建仍为 Debug。

## 复验

`scripts/test_diagnostics.ps1`：构建、客户端 JVM 回归、诊断隐私/故障测试、页面操作、实际系统另存和独立 UID 接收校验。只操作指定开发模拟器，使用已有 QA 文件接收应用。
