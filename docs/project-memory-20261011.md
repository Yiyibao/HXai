# 项目分组与手动记忆

2026-10-11 用户需求：项目用于按特殊需求整理对话；记忆支持用户手动增加。实现基于现有 Flutter 主界面、Kotlin 功能层和本地 Room 存储。

## 使用方式

- 打开聊天侧栏，点击“项目”右侧的 **+**，输入项目名称。
- 展开项目查看聊天；项目右侧菜单可新建项目聊天、重命名或删除分组。
- 聊天的“更多操作”提供“移动到项目 / 移出项目”。每个聊天最多归属一个项目；分组聊天在项目下展示，普通聊天在最近聊天中展示。
- 删除分组会将聊天移回普通聊天，保留聊天正文。
- 聊天“更多操作”支持置顶/取消置顶。置顶聊天在最近聊天日期分组之前显示，状态保存到原生数据库，不依赖 Flutter 内存。
- “归档聊天”会从普通历史、普通搜索和项目列表中隐藏聊天，但保留正文和项目归属。侧栏“已归档聊天”可查看、搜索和继续加载旧记录，并通过“取消归档”恢复原分组；“返回最近聊天”切回普通列表。
- 设置 → 记忆 → 右上角 **+**，选择“偏好”或“背景信息”，输入内容并保存。内容上限为 2000 字。
- 手动记忆的来源显示“手动添加 / 用户直接输入”，保存后可在原记忆页面查看、编辑和删除；使用记忆开关继续控制聊天是否调用这些记录。

## 存储与保护

项目复用现有 `conversation_folder` 和 `folder_id`，无需数据库迁移，沿用现有完整备份。项目和聊天归属按档案及助手校验，写入使用事务；过期档案请求返回错误。

聊天归档使用 Room 31→32 非破坏性迁移新增的 `is_archived` 字段；置顶复用 `is_pinned`。两种状态按档案与上下文 epoch 校验，经会话元数据锁同步数据库及运行中会话，流式检查点不会覆盖独立修改的状态。完整备份保留这些字段。

手动记忆保存在已有记忆存储中，标记 `USER_MANUAL` 和 `SELF_REPORTED`。它不依赖聊天来源，聊天变更不会使它失效，编辑时保留手动来源及版本历史。偏好和背景进入已有相关记忆检索。手动录入不作为独立作答证据，不提高学习掌握度。

手动保存按档案与请求编号去重。删除后，同一旧请求不能再次生成已删除记录；用户重新添加使用新请求。备份恢复保留当前较新的手动修改，并遵守已有删除抑制规则。
