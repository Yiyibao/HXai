# 侧栏与高亮色

2026-10-11。侧栏按用户采纳的参考图实现：搜索框、新聊天、图片、文件库、项目、按日期分组的最近聊天，以及固定的档案／设置栏。主要内容共同滚动，避免项目展开或大字模式挤压历史列表。

图片与项目仍为占位：图片入口提示即将推出；项目可收起／展开提示，新建项目按钮提示即将推出。没有生成图片、创建项目、保存分组或移动对话的业务实现，也不显示虚构的项目数据。

设置首页与“外观与交互”均可打开“高亮色”。七种选项：蓝、绿、黄、粉、橙、紫，以及浅色显示为黑色、深色显示为白色的中性选项。默认粉色，保留采纳稿的浅粉选中背景。

参考 [ChatGPT 官方外观说明](https://help.openai.com/en/articles/11958281-updating-your-visual-experience-on-chatgpt)：强调色与深浅主题独立，作用于气泡、按钮与高亮元素；部分元素保留自身颜色保证可读性。具体色值及浅色选中填充为本应用适配，并非声称复刻 ChatGPT 的内部色值。

本应用作用范围：侧栏选中项、用户消息气泡、发送／停止按钮、主题主按钮、开关与复选框选中状态、选中标签、输入焦点边框、文本光标及文字选择。正文、整体背景、输入框背景、图表数据颜色与错误颜色不随高亮色改变。颜色选择立即更新，选择器提供实时气泡／按钮预览。

保存使用现有 Android `study_appearance` 本机偏好，键为 `accentColor`。旧安装或未知值回退粉色；切换档案不改变本机外观。当前没有账号外观同步，重启可恢复。

验收证据见 `qa/sidebar-accent-20261011/`。
