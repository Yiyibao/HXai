# 三次含参单调符号表 v1

`professional_multivariate` 的 `cubic_monotonicity` 只认证导数恰好为 \(Kx^2+La\) 的多项式。K、L 是有理常数，K 非零。

a=0 的严格性来自立方差恒等：\(v^3-u^3=(v-u)(v^2+uv+u^2)\)，二次因子是平方和，u<v 时不为零。两临界点的符号来自 \(x^2-r^2=(x-r)(x+r)\) 的实线序，不是参数采样。

含 x 的一次导数项、参数高次、一般含参不等式、极值和图像都不在本证书内，返回 UNSUPPORTED，不判命题为假。

宿主只识别「完整讨论」且要求处理退化边界的题面。只问导数是否已完成分类的题不走这条路径。已有工具计划或已派发调用不被文本路径擦除。
